# ESP32-C6-Firmware

Dieses Verzeichnis ist vorbereitet, enthält aber noch keinen Firmwarecode. Im geprüften Workspace war kein Arduino- oder ESP-IDF-Projekt und kein Sensor-/Motorcode vorhanden.

Die Smartphone-App erwartet einen GATT-Server gemäß [`../docs/ble-protocol.md`](../docs/ble-protocol.md). Sobald das bestehende ESP32-Projekt verfügbar ist, Framework und Pins/Sensor-API prüfen und BLE modular integrieren, statt angenommene Messwertfunktionen einzubauen.
